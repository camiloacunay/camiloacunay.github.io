Prompt completo para análisis EDA

Tengo un conjunto de datos de ventas de comercio electrónico llamado ecommerce_sales.csv. Por favor, realiza un análisis exploratorio de datos (EDA) completo sobre él. Quiero ver:

  • Dimensiones del dataset, tipos de datos (dtypes) y un resumen de valores nulos.
  • Estadísticas descriptivas para todas las columnas numéricas.
  • Gráficos de distribución para los ingresos (revenue) y la cantidad (quantity).
  • Un mapa de calor de correlaciones para todas las columnas numéricas.
  • Los 5 productos y categorías principales según ingresos totales.
  • Desglose de los ingresos por región.
  • Identifica y señala cualquier outlier, anomalía o problema de calidad de datos que encuentres.

Guarda todos los gráficos como archivos PNG y entrégame un resumen escrito de los principales hallazgos.

Prompt para limpieza de datos de clientes

Tengo un conjunto de datos de clientes desordenado llamado messy_customer_data.csv.

Por favor, límpialo completamente:

  • Estandariza customer_name a formato Title Case.
  • Corrige y valida los formatos de email, marcando los que sean inválidos.
  • Estandariza los números de teléfono al formato (XXX) XXX-XXXX.
  • Convierte todos los valores de signup_date a un formato de fecha consistente YYYY-MM-DD.
  • Limpia Annual_Revenue: elimina $ y comas, y conviértelo a tipo float.
  • Estandariza Country utilizando el nombre completo del país.
  • Corrige Age: elimina valores imposibles (menores que 0 o mayores que 120) y conviértelo a tipo integer.
  • Estandariza is_active a valores booleanos True/False.
  • Elimina las filas duplicadas.

Muéstrame una comparación del antes y después y guarda los datos limpios como cleaned_customer_data.csv.

Prompt para crear un dashboard HTML de métricas empresariales

Tengo un archivo llamado dashboard_data.csv con 2 años de métricas empresariales mensuales, correspondientes a 4 regiones y 3 líneas de productos.

Crea un dashboard en HTML con las siguientes visualizaciones:

  1. Tendencia de ingresos por región
    • Un gráfico de líneas que muestre los ingresos a lo largo del tiempo.
    • Una línea por cada región.
  2. Clientes nuevos vs. clientes perdidos (Churned Customers)
    • Un gráfico combinado.
    • Barras para los clientes nuevos.
    • Línea para los clientes perdidos.
    • Debe mostrar las tendencias mensuales.
  3. Evolución del NPS
    • Un gráfico de líneas que muestre cómo ha evolucionado el NPS Score a lo largo del tiempo.
  4. Resumen de KPIs (Summary Scorecard)
    • Para el mes más reciente (diciembre de 2024), muestra:
    • Ingresos totales.
    • Clientes nuevos.
    • Tasa de abandono o Churn Rate (%).
    • NPS promedio.

Haz que el dashboard tenga una apariencia profesional, como algo que podría mostrar al equipo directivo de la empresa.

Utiliza un esquema de colores limpio, un diseño responsive y asegúrate de que sea algo que pueda abrir directamente en cualquier navegador web.
